Quick Setup Guide

Windows. Four steps and you are chatting.

  1. Extract the folder Extract the ZIP anywhere. A USB drive works too.
  2. Run setup.bat once Needs internet. It downloads the engine and the model. Skip this if your download already includes the bin/ and models/ files.
  3. Run start.bat, then press ENTER Wait until the window says the server is listening.
  4. Open the chat in your browser http://127.0.0.1:8080  Copy
The address is http://, not https://. This is normal for a local app and is private to your computer. Close the terminal window to stop the AI.

Folder layout

NexoraAI/
├── start.bat      <- run the AI
├── setup.bat      <- one-time download of engine + model
├── bin/           <- llama.cpp (llama-server.exe and DLLs)
└── models/        <- gemma-3-270m-it-Q8_0.gguf

Manual download (if setup.bat fails)

  • Engine Download the win-cpu-x64 zip and extract everything into bin/. llama.cpp releases →
  • Model Download gemma-3-270m-it-Q8_0.gguf into models/. Hugging Face →

Notes

  • Small modelGemma 3 270M is tiny. It is fast on any PC, but its answers are basic. Larger GGUF models (1B-4B) work too: put the file in models/ and edit the filename in start.bat.
  • Safety tuningThe default model has built-in safety tuning. Other community GGUF models may behave differently; check each model's license and quality yourself.
  • Different portChange 8080 in start.bat.
  • Linux / macOSUse the matching llama.cpp build and run llama-server -m models/<file>.gguf --port 8080.
