Quick Start (Windows)

Eight simple steps and you are chatting.

  1. Extract the ZIP file Extract the ZIP file anywhere on your computer. A USB drive works too.
  2. Double-click setup.bat Do this while connected to the internet.
  3. Read the instructions in the terminal Press Y, then ENTER, to begin setup.
  4. Let the setup download everything The setup script downloads the llama.cpp runtime and the Qwen model automatically.
  5. Wait for [COMPLETED] Wait until the terminal displays [COMPLETED].
  6. Double-click start.bat This starts the local server.
  7. Open the chat in your browser Your default browser should open the NEXORA Local AI chat interface automatically. If it does not, open this address manually:
    http://127.0.0.1:8080/index.html  Copy
  8. Start chatting! Enjoy your private, offline AI.
Keep the terminal window open while using the AI. Press Ctrl+C in that window to stop the server.
The address uses http://, not https://. This is normal for a local application. The server listens on 127.0.0.1, so it is intended to be accessible only from your own computer.
